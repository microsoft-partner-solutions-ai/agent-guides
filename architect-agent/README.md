## Architect Agent Replication Guide

**Agent Name**: Architect Agent

**Description**: Architect Agent supports solution architects in working with partners and customers on their technical use cases.

**Target Use Cases**: 
- Use case ideation and prioritization
- Technical research and tradeoffs (using Microsoft Learn and GitHub samples as knowledge sources)
- Architecture diagram generation prompt to be used with GitHub Copilot based on meeting notes/transcripts
- Synthetic data generation for POC development
- Co-sell webinar agendas and talk tracks

## How to Create your Agent

1. Navigate to copilot.microsoft.com

2. On the left pane, select "New agent"

3. Under the "Configure" tab, add the content documented in this folder.

4. Hit the "Create" button on the upper right

5. Select "Go to agent" to navigate to agent and test, or select "Share" to get share link and select who the agent should work for.
